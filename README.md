# Casa de Apoio Maná de Deus

Primeira versão estática do site institucional da Casa de Apoio Maná de Deus, em Jataí-GO.

## Como visualizar

Abra `index.html` no navegador. A versão atual não precisa de servidor ou dependências.

## Próxima etapa técnica

O painel de colaboradores está apresentado como fluxo demonstrativo. Antes de usar dados reais, integrar autenticação, banco de dados, permissões por função, auditoria e proteção adequada para dados pessoais sensíveis.
